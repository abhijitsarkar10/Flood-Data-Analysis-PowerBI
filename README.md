# Flood-Data-Analysis-PowerBI
Flood Data Analysis & Power BI Dashboard

## 📊 Project Overview

This project presents an interactive Power BI dashboard that analyzes global flood data and explores patterns in flood frequency, fatalities, severity, causes, and financial damage.

The dashboard uses interactive visualizations, KPI cards, filters, and geographical analysis to make the data easier to explore and understand.

## 🎯 Objectives

- Analyze the number of reported flood events
- Examine fatalities by flood cause and severity
- Analyze financial damage caused by floods
- Compare flood severity across countries
- Identify major causes associated with flood-related deaths
- Explore the geographical distribution of flood events
- Analyze flood patterns across different years

### Key Performance Indicators

- Total Deaths

### Visualizations

- Country-wise flood severity analysis
- Deaths by main flood cause
- Deaths by severity
- Country-wise financial damage
- Geographic distribution of flood events

## 🔍 Analysis

The dashboard allows users to explore:

- Flood severity across different countries
- Causes associated with flood-related deaths
- Financial damage across countries
- Geographic distribution of flood events
